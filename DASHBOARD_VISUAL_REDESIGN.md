# Dashboard visual redesign

The doctor dashboard uses a dark-pastel medical SaaS style. The sidebar and workspace use layered ink/navy surfaces, while mint, lavender, powder-blue, blush and muted-gold accents distinguish actions, consultation categories and statuses.

The redesign includes:
- Overview hero with a date badge and quick actions.
- Four elevated KPI cards with distinct pastel accent rails.
- Responsive two-column overview panels.
- Dedicated consultation service cards with readable service names, duration, fee and capacity.
- Refined schedule and appointment cards/tables.
- Improved form fields, focus states, buttons, hover transitions and mobile layout.

The active Flask/Jinja template remains `src/doctor/templates/doctor_dashboard.html`. Existing API element IDs and event handlers are preserved.
