# MediSlot Dark Pastel Theme

The active doctor dashboard template is `src/doctor/templates/doctor_dashboard.html`.

The current design combines a deep ink/navy workspace with pastel accents:
- mint/sage for primary actions and success states;
- lavender for consultation and supporting accents;
- powder blue for quick consultations and information;
- blush for cancellations and destructive actions;
- soft gold for warnings and clinic-style consultation cards.

The layout is also refined, not just recoloured: the overview has a redesigned hero and quick actions, statistics use elevated cards, the two overview tables sit in a responsive split layout, consultation types use individual cards, and schedule/blackout/forms/tables have consistent spacing, hierarchy, depth and hover states.

The existing template IDs, Flask routes, API requests, and form interactions are retained.
