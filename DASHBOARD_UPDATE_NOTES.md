# MediSlot dashboard update

The active Flask doctor dashboard is `src/doctor/templates/doctor_dashboard.html`.

This release introduces a complete dark-pastel workspace treatment:
- deep ink/navy shell and sidebar;
- pastel mint, lavender, powder-blue, blush and warm-gold service accents;
- redesigned overview hero with quick actions;
- elevated statistic, consultation, schedule and blackout cards;
- stronger table hierarchy, form focus states, hover feedback and responsive layouts.

Existing element IDs, API calls, and form behavior are retained so the current Flask/API integration continues to work.
